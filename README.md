# Mi Entreno

App personal (PWA) para entrenar en casa: rutina de 5 días, interval timer de cardio, registro de ejercicios con historial de progreso y control de peso. Todo se guarda **localmente** en el teléfono (localStorage), sin cuentas ni servidores.

## Funciones
- **Hoy**: rutina del día (lunes a viernes), 30 min de cardio + fuerza. Registra kg/reps por serie, muestra lo que hiciste la última vez y lanza el descanso automático al marcar ✓.
- **Cardio**: interval timer con calentamiento, trabajo/descanso, series, vuelta a la calma, pitidos, voz y vibración. 5 protocolos + uno personalizable.
- **Progreso**: gráfico por ejercicio (peso máximo, volumen, reps) e historial de cardio.
- **Peso**: peso corporal, cintura y meta con gráfico.
- **Rutina**: la semana completa, guía de progresión y respaldo (exportar/importar JSON).

## Equipo
Set de mancuernas ajustables 20 kg (con barra), colchoneta y tabla de flexiones.

## Instalar en el teléfono
Abre la página de GitHub Pages en el navegador → menú → **Agregar a pantalla de inicio** (Android/Chrome) o **Compartir → Agregar a inicio** (iPhone/Safari).
